Play FireRed Standard IronMON on a Miyoo Mini Plus with the original Ironmon
Tracker beside or below the game. The app uses Onion's gpSP core, prepares
randomized runs on the handheld, and provides enemy stat markings, suspected
abilities, notes, fast-forward, autosave and Standard rule guards. Playing and
resetting require no PC, server or WiFi after setup.

Install using the guided Windows SD-card installer, or the Python installer
for Python 3.11+. Setup downloads dependencies and prepares game files locally.
You must supply your own unmodified FireRed USA Rev 1 ROM and GBA BIOS; these
are not included in the downloads.

Tested on **Miyoo Mini Plus with Onion v4.4.0-beta-20260120-07505ea5**.
The original Miyoo Mini and other Onion versions, including 4.3, are unverified.
An [owner-completed main-story run and validation record](https://github.com/TrissyGE/miyoo-ironmon/blob/main/docs/VALIDATION.md)
documents the final team, testing scope and development-run repairs.

Source and licensing details are available in the project repository. Custom
development substantially used OpenAI Codex; see the
[AI disclosure](https://github.com/TrissyGE/miyoo-ironmon/blob/main/AI_USAGE.md).
