# TIC-80 ✔

<img src="https://user-images.githubusercontent.com/44569252/188293085-b0a1c5a9-ee58-4334-ae39-dfc128d9a9da.png" align="right" width="90" />

- Emulator: **lr-tic80**
- Rom Folder: `TIC`
- Extensions: `.tic`
- Bios: None

TIC-80 1.4.1, built for the Miyoo's Cortex-A7. It runs carts made for TIC-80 1.x, including ones that use `vbank`.

Supported cart languages: Lua, MoonScript, YueScript, Fennel, JavaScript, Wren, Squirrel, Python, Scheme and WASM. Carts written in Ruby, Janet, Gravity or MiniScript don't run.

The CPU runs on the performance governor while a game is playing, and the picture keeps its aspect ratio (black bars above and below) instead of being stretched.
